Architecture Review

RSAcademy separates core carving, forensic analysis, visualization, reporting, and CLI orchestration.

Input → BinaryReader → Backend selection → Header/Footer matcher
     → Validator → Artifact model → Entropy/Hashes → Offset map
     → JSON/HTML/ASCII reports → CLI or batch summary

Design decisions

The built-in Python backend is the reference implementation. The optional YARA seam is isolated in backends; reports do not know backend internals. Batch processing delegates every file to rsa_one.
