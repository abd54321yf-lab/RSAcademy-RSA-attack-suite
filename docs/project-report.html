1. المشكلة والدافع

قد تبقى أجزاء من الملفات المحذوفة أو التالفة داخل صورة قرص أو ملف ثنائي دون وجود اسم ملف أو بنية نظام ملفات قابلة للاستخدام. يعالج المشروع هذه المشكلة من خلال البحث عن أنماط معروفة بدل افتراض أن كل البيانات منظمة مسبقًا.

السؤال الهندسي

كيف نحدد بداية ملف محتمل ونهايته بأمان، ثم نتحقق من معقوليته ونوثق مكانه وحالته دون إخفاء حالات التلف أو الادعاء باسترجاع غير مؤكد؟

القيمة التعليمية

يجمع المشروع بين مفاهيم Cybersecurity وDigital Forensics وهندسة البرمجيات في مسار واضح يمكن شرحه شفهيًا واختباره بعينات ثنائية اصطناعية.

قرار التصميم

النواة لا تعرف شيئًا عن HTML أو CLI. الـ Backend يعيد نموذجًا موحدًا، والتقارير تستهلك النموذج بدل أن تدخل في تفاصيل المطابقة.

3. التنفيذ والمكونات

Core RSA

signature.py يعرّف التواقيع. reader.py يتحقق من المسارات والـ offsets. matcher.py يبحث عن Header/Footer بحدود تمنع الحلقات غير المنتهية.

Analysis

entropy.py يحسب Shannon Entropy. fragment.py يبني RsaArtifact ويحل التداخل. يتم تسجيل MD5 وSHA-256 وحالات التلف.

Output + CLI

ينتج النظام تقارير JSON وHTML وASCII وملفات مستخرجة. الأوامر تشمل carve وbatch وcarve-list وrun.

python3 main.py carve samples/mixed.bin --output results python3 main.py batch samples --recursive --pattern '*.bin' python3 -m unittest discover -s tests -v

6. المنظور الجنائي والأمني

Magic Bytes وOffset

التوقيع يحدد مرشح البداية، بينما الـ Offset يربط الأثر بموقعه داخل المصدر ويساعد على إعادة الفحص.

Entropy Anomaly

الارتفاع الشديد قد يشير إلى ضغط أو تشفير أو بيانات packed، لكنه ليس دليلًا منفردًا على وجود برمجية خبيثة.

Integrity Verification

تسجيل MD5 وSHA-256 يتيح مقارنة الأثر المستخرج أو توثيق تغيره أثناء المعالجة.

Slack Space وAnti-Forensics

المشروع يجهز مفهوم الخرائط والمناطق غير المعينة، بينما يتطلب التصنيف الكامل معرفة بنظام الملفات.

7. القيود وخطة التطوير

لا يدّعي المشروع استرجاع الملفات المجزأة بدرجة عالية أو تحليل نظام ملفات كامل. هذه الحدود موثقة لتجنب تقديم نتيجة جنائية غير مؤكدة.

القيود الحالية

المطابقة الحالية تعتمد على تواقيع معروفة. القراءة في الإصدار الأول تركز على صحة التنفيذ، وقد تحتاج الصور الضخمة جدًا إلى Streaming matcher متقدم.

الخطوات المستقبلية

إضافة Validators أعمق، تحليل Filesystem-aware للـ Slack Space، دعم SVG تفاعلي، تحميل YARA Rules، وParallel workers بعد قياس الأداء.
